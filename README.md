# zulqarnain-nadabo

Personal site. Next.js (App Router) + Tailwind CSS. No other runtime dependencies.

## Run
    npm install
    npm run dev      # http://localhost:3000
    npm run build

## Deploy (Vercel)
Push to a Git repo and import it in Vercel, or run `npx vercel --prod` in this folder.
Framework preset: Next.js (auto-detected). No environment variables.

## Edit
- Copy and links: `lib/content.js` (only publicly stated facts).
- Colours and fonts: `tailwind.config.js`, `app/layout.jsx`.
- Layout: `components/`. Section order: `app/page.jsx`.
- Photo: replace `public/zulqarnain.jpg` (portrait, about 760px wide or more).

## Rules for the content
No metrics, no invented partners, no campaign language. Civic Mandate is always described as a pilot-grade public record.
